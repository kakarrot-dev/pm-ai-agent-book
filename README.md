# AI Agent 产品经理实战

一本围绕 Agent 产品完整生命周期展开、帮助 AI 产品经理做出关键产品判断的实战教材。

## 本书解决的问题

本书关注的不是如何从头实现一个 Agent，而是产品经理在真实工作中需要回答的问题：什么需求值得 Agent 化，应该给 Agent 多大自主权，怎样设计用户控制权，如何把产品需求映射为能力方案，以及怎样评估、上线和持续运营 Agent 产品。

## 目标读者与非目标

本书适合已有传统产品经验、希望转型为 AI 产品经理的读者，也适合正在从事 AI 产品工作、希望系统补齐 Agent 产品方法论的读者。阅读不要求具备编程、模型训练或 Agent 工程经验。

本书不是 Agent 编程或模型训练教程，不从零讲授通用用户研究、PRD 和项目管理基础，也不讨论传统推荐、预测、风控等非生成式 AI 产品。

## 内容特色

- 按产品生命周期组织，从机会识别推进到规模化经营。
- 用客户服务与事务办理 Agent、企业知识与办公 Agent 两条案例线贯穿全书。
- 围绕产品判断讲解必要技术，不用技术名词代替用户问题。
- 每章提供检查表、模板或思考题，帮助读者复核实际项目决策。

更详细的书稿定位、案例线和图示约定见[书稿说明](book/README.md)。

## 推荐阅读路径

第一次阅读建议从引言开始按顺序阅读：第 1 至 3 章判断“是否值得做”，第 4 至 6 章回答“应该做成什么”，第 7 至 9 章讨论“如何证明有效并稳定经营”，第 10 章讨论能力扩展与组织建设。

正在推进具体项目的读者，可以直接进入对应章节，使用章末检查表或模板复核当前决策。
