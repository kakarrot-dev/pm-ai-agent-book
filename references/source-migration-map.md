# 原书内容迁移表

## 使用说明

本表记录原书《深入理解 AI Agent：设计原理与工程实践》到本项目入门篇 `book1/` 的内容迁移关系。原书始终作为只读来源，入门篇只迁移能够支持产品判断的内容。

进阶篇 `book2/` 是在入门篇产品方法基础上独立扩展的产品工程教程，不使用本表表达逐章迁移关系。涉及外部框架、论文和课程的内容，在对应章节中直接保留来源链接。

处理方式只使用以下四种状态：

- `保留改写`：保留核心观点，改为产品问题与决策语言。
- `压缩迁移`：只保留支持产品判断的结论，删除技术展开。
- `仅作案例`：不讲授原技术主题，只保留有代表性的产品案例。
- `不迁入`：不进入新版正文，原内容继续保留在原书。

核查状态使用：`待迁移`、`已迁移并复核`、`不迁入并保留原文`。
